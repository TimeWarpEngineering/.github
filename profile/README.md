## Agents

Each project above keeps its own kanban board under `kanban/`. Coding agents work those tasks. This organization has the Claude, Grok, and Cursor GitHub apps installed. Recent commits on the suite include Claude and Grok as co-authors.

Ganda is the CLI that launches those agents. A profile (`implementer-grok`, `implementer-opencode`, or `implementer-cursor`) takes a kanban task, and `ganda repo audit` is the repository gate. The Ganda repository is private, and the tool is not published to NuGet.

[TimeWarp.Skills](https://www.nuget.org/packages/TimeWarp.Skills) is the public CLI for installing agent skills (`dnx TimeWarp.Skills`). Docs: [timewarp.software/skills](https://timewarp.software/skills/).
[![NuGet](https://img.shields.io/nuget/vpre/TimeWarp.Skills?logo=nuget)](https://www.nuget.org/packages/TimeWarp.Skills)
